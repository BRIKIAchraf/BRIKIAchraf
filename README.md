## ⭐ Featured data, ML & cloud projects

### [CDC Lakehouse NYC](https://github.com/BRIKIAchraf/cdc-lakehouse-nyc)

A change-data-capture and analytics platform for NYC taxi data.

```text
NYC TLC → PostgreSQL → Debezium CDC → Kafka
       → Spark Structured Streaming → Apache Hudi on S3
       → Snowflake → dbt marts → BI & analytics
```

### Engineering focus

| Capability | What it demonstrates |
|---|---|
| 🔁 Replayability | Historical reloads and Kafka-based reprocessing |
| 🧩 Data contracts | Versioned events and controlled schema evolution |
| ⚡ Idempotence | Safe upserts and duplicate protection during replay |
| ✅ Data quality | Key, timestamp, geographic, and business-rule checks |
| 🔍 Observability | Lag, freshness, rejected records, throughput, and batch duration |
| 🧭 Lineage | OpenLineage/Marquez-oriented traceability |
| 🔐 Security | Secrets outside Git and least-privilege principles |

> **Status:** portfolio blueprint with the architecture, data model, roadmap, and validation principles documented. Implementation is being built incrementally.

Modern data platform combining streaming and batch workloads with Kafka, Flink, Spark, Delta Lake, Snowflake, dbt, Airflow, MLflow, DataHub, and Great Expectations.

### [Smart Factory Data Pipeline](https://github.com/BRIKIAchraf/Smart-Factory-Data-Pipeline)

Industrial IoT architecture connecting PLC/Modbus telemetry to MQTT, Kafka, InfluxDB, PostgreSQL, Grafana, and a real-time React control center, with store-and-forward resilience and anomaly detection.

### [Predictive Maintenance System](https://github.com/BRIKIAchraf/Predictive-Maintenance-System)

Industrial AI platform concept covering feature stores, MLflow, drift detection, Spark Streaming, edge inference, federated learning, and S3-compatible data storage.

### [Industry 5.0 Digital Twin Factory](https://github.com/BRIKIAchraf/Industry-5.0-Digital-Twin-Factory)

Industrial IoT and digital-twin platform combining Unified Namespace, edge intelligence, an AI copilot, energy/CO2 monitoring, FastAPI, InfluxDB, Grafana, and React.

### [Industrial Cloud Platform](https://github.com/BRIKIAchraf/Industrial-Cloud-Platform)

Industry 4.0 architecture connecting simulated PLC/OPC-UA systems to Node-RED, MQTT, Kafka, InfluxDB, Grafana, and Keycloak.

### [Predictive Maintenance SVD](https://github.com/BRIKIAchraf/Plateforme-Industrielle-de-Maintenance-Pr-dictive-SVD-)

Anomaly-detection platform using truncated/randomized SVD, residual scoring, EWMA alerting, Redis state, MLflow tracking, Kafka, and Prometheus/Grafana.
