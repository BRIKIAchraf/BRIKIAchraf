## ⭐ Featured projects

### 01 · [CDC Lakehouse NYC](https://github.com/BRIKIAchraf/cdc-lakehouse-nyc)

CDC and analytics architecture for NYC taxi data:

~~~text
NYC TLC → PostgreSQL → Debezium → Kafka → Spark Structured Streaming
       → Apache Hudi on S3 → Snowflake → dbt marts → BI & analytics
~~~

**Key themes:** replayability · idempotent upserts · schema contracts · data quality · lineage · observability

### 02 · [E-Commerce Data Platform](https://github.com/BRIKIAchraf/E-Commerce-Data-Platform-Data-Lakehouse-Data-Mesh-)

Modern data platform combining real-time and batch processing with Kafka, Flink, Spark, Delta Lake, Snowflake, dbt, Airflow, MLflow, DataHub and Great Expectations.

### 03 · [Smart Factory Data Pipeline](https://github.com/BRIKIAchraf/Smart-Factory-Data-Pipeline)

Industrial IoT pipeline connecting PLC/Modbus telemetry to MQTT, Kafka, InfluxDB, PostgreSQL and Grafana, with edge buffering, monitoring and anomaly detection.

### 04 · [Industry 5.0 Digital Twin Factory](https://github.com/BRIKIAchraf/Industry-5.0-Digital-Twin-Factory)

Digital-twin architecture built around Unified Namespace, edge intelligence, AI-assisted operations, energy/CO₂ monitoring, FastAPI, InfluxDB and Grafana.

### 05 · [Predictive Maintenance SVD](https://github.com/BRIKIAchraf/Plateforme-Industrielle-de-Maintenance-Pr-dictive-SVD-)

Anomaly-detection system using truncated/randomized SVD, residual scoring, EWMA alerting, Redis state, MLflow tracking, Kafka and Prometheus/Grafana.

### 06 · [Multimodal Human-Machine Interface](https://github.com/BRIKIAchraf/Interface-Machine-multimodale-Avanc-e)

AI interaction prototype combining gesture recognition, speech commands, facial-expression analysis and multimodal decision rules with Python and OpenCV.
