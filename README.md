## Featured data engineering project

### CDC Lakehouse for NYC Taxi Analytics

A portfolio architecture for a complete CDC and analytics platform around New York City taxi data.

**Pipeline:** NYC TLC data → PostgreSQL → Debezium CDC → Kafka → Spark Structured Streaming → Apache Hudi on S3 → Snowflake → dbt marts

**Engineering focus:**

- Replayable ingestion and schema contracts
- Idempotent upserts and logical exactly-once processing
- Data quality checks for keys, timestamps, and geographic values
- Weather enrichment through Open-Meteo and Airbyte
- Monitoring for Kafka lag, freshness, rejected records, and batch duration
- Lineage and observability with OpenLineage, Prometheus, and Grafana

> Status: portfolio blueprint with the architecture, data model, roadmap, and validation principles documented. Implementation is being built incrementally.
